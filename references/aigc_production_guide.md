# AIGC生产指南（欧美真人感 / 高级脸 / 质感 / 光线）

> 本文档为CIRCUL超级视觉场景库生成器的AIGC生产参考，所有场景生成、AIGC素材生产必须严格遵守本文档中的视觉规范。

## 一、欧美真人感人物标准

### 1.1 人物年龄与外貌

| 维度 | 标准 | 禁止 |
|------|------|------|
| 年龄 | 28-45岁为主（目标人群），可扩展至25-50岁 | 18岁以下、60岁以上（非目标人群） |
| 人种 | 欧美白人为主，可适度包含亚裔/拉丁裔/非裔 | 单一亚洲面孔（品牌定位欧美市场） |
| 皮肤 | 真实皮肤纹理：毛孔、雀斑、细纹、自然肤色不均 | 塑料感、过度磨皮、完美无瑕、蜡像感 |
| 面部 | 高级脸：骨相清晰、五官有辨识度、非网红模板脸 | AI网红脸、完美对称、标准假笑、过度精致 |
| 身材 | 真实身材：有肌肉线条、有自然体态、非完美模特 | 过度健美、病态瘦、完美比例 |

### 1.2 人物状态与表情

| 场景类型 | 人物状态 | 表情 |
|---------|---------|------|
| 晨间日常 | 刚起床的慵懒、专注做咖啡、瑜伽的平静 | 平静、专注、微微笑意 |
| 工作压力 | 会议中的专注、加班的疲惫、呼吸训练的放松 | 专注、疲惫、放松、内观 |
| 社交饮食 | 约会的温柔、品酒的专注、聚餐的开心 | 温柔、专注、开心、微醺 |
| 运动户外 | 运动中的专注、登顶的满足、休息的疲惫 | 专注、满足、疲惫、深呼吸 |
| 旅行时差 | 飞行的疲惫、度假的放松、倒时差的困倦 | 疲惫、放松、困倦、好奇 |
| 晚间睡眠 | 睡前的放松、深度睡眠的平静、起床的慵懒 | 放松、平静、慵懒、安睡 |
| 女性健康 | 经期的不适但自我关怀、SPA的享受 | 温柔、自我关怀、享受、接纳 |
| 家庭礼赠 | 亲子的温暖、伴侣的亲密、收礼的惊喜 | 温暖、亲密、惊喜、感动 |
| 正念提升 | 冥想的内观、呼吸训练的专注、压力记录的觉察 | 内观、专注、觉察、平静 |
| 特殊极限 | 高原的挑战、跨时区的透支、生病的虚弱 | 挑战、透支、虚弱、恢复 |

### 1.3 核心原则：80%不看镜头

- **80%的场景**：人物不看镜头，专注于正在做的事（喝咖啡、品酒、运动、工作、冥想）
- **20%的场景**：人物看镜头或半看镜头（礼赠惊喜、自我关怀、肖像类）
- **目的**：营造真实生活感，避免广告摆拍感，让用户产生「这就是我」的代入感

## 二、电影级光线标准

### 2.1 六种核心光线类型

| 光线类型 | 适用场景 | 特点 | 参考 |
|---------|---------|------|------|
| Golden Hour黄金时刻 | 晨间日常、运动户外、旅行 | 暖金色低角度光，长阴影，温暖浪漫 | 电影外景、Oura户外场景 |
| 窗边柔光 | 工作压力、晨间日常、家庭礼赠 | 柔和侧光，明暗过渡自然，真实室内感 | Apple生活场景、Kinfolk杂志 |
| 烛光暖光 | 社交饮食、晚间睡眠、女性健康 | 暖暗调，点光源，柔和阴影，浪漫氛围 | 高级餐厅、约会场景、Aesop广告 |
| 高海拔自然光 | 运动户外、特殊极限 | 冷蓝调，强烈日光，清晰阴影，壮阔感 | Patagonia户外、国家地理 |
| 机舱冷光 | 旅行时差 | 冷调人工光+舷窗自然光，疲惫感 | 商务舱大片、旅行杂志 |
| 极暗微光 | 晚间睡眠 | 月光/小夜灯，蓝紫色微光，静谧感 | Oura睡眠场景、高级卧室 |

### 2.2 光线原则

1. **自然光为主**：90%场景使用自然光或模拟自然光，禁止棚拍感
2. **禁止正面平光**：禁止闪光灯正面打光、无影光、均匀照明
3. **柔和阴影**：阴影边缘柔和，明暗过渡自然，有空气透视感
4. **方向性**：光线有明确方向（侧光、逆光、侧逆光），营造立体感
5. **真实光源**：画面中有可见光源（窗户、蜡烛、台灯、阳光），逻辑自洽

## 三、真实质感要求

### 3.1 皮肤质感

| 维度 | 标准 |
|------|------|
| 纹理 | 可见毛孔、雀斑、细纹、皮肤纹理 |
| 光泽 | 自然油光、T区微亮、非哑光塑料感 |
| 汗水 | 运动场景有真实汗水（额头、颈部、手臂） |
| 肤色 | 自然肤色不均、有红晕、非完美均匀 |
| 毛发 | 可见汗毛、眉毛纹理、头发丝缕分明 |

### 3.2 产品质感（CIRCUL 3戒指）

| 维度 | 标准 |
|------|------|
| 材质 | 钛金属真实质感，非塑料感 |

| 尺寸 | 2.23mm超薄，比例准确，非夸张厚戒 |
| 佩戴 | 贴合手指，有真实接触感，非悬浮 |

| 颜色 | 钛金属原色/深空灰/玫瑰金，真实金属色 |

### 3.3 环境材质

| 材质类型 | 真实感要求 |
|---------|-----------|

| 颜色 | 使用场景 | 使用比例 |

- ❌ 渐变彩虹色、过度滤镜色

## 五、构图原则

### 5.1 核心构图原则

1. **大量留白**：人物/产品占画面30-40%，其余为环境/留白
2. **局部特写**：80%场景为手部/戒指/上半身特写，非全身照
3. **动态瞬间**：捕捉动作中的瞬间（倒水、碰杯、跑步、呼吸），非静态摆拍
4. **景深虚化**：浅景深，背景虚化（bokeh），突出主体
5. **不对称构图**：黄金分割、三分法，非居中对称
6. **环境叙事**：背景有故事感（餐厅、卧室、户外、办公室），非纯色背景

### 5.2 产品展示方式

| 展示方式 | 适用场景 | 特点 |
|---------|---------|------|
| 手部佩戴特写 | 所有场景 | 戒指在手指上，与动作结合，最自然 |
| 道具同框 | 社交饮食、晨间日常 | 戒指与咖啡杯、红酒杯、钢笔等同框 |
| 环境反射 | 高端场景 | 戒指反射周围环境光，展示质感 |
| 产品精修 | 详情页、主图 | 纯色/渐变背景，产品单独展示 |
| 双人佩戴 | 家庭礼赠、伴侣场景 | 两人手部同框，情侣款展示 |

| 素材类型 | 尺寸比例 | 分辨率 | 用途 |
|---------|---------|--------|------|
| Hero主视觉 | 16:9 / 9:16 | ≥2048px | 网站首页、广告首图 |
| 模块配图 | 4:3 / 1:1 | ≥1600px | 网站内容模块、社媒 |

| 邮件素材 | 16:9 / 1:1 | ≥1200px | EDM、营销邮件 |

### 7.2 命名规范

```
CIRCUL3_[场景编号]_[类型]_[比例]_[序号].jpg

示例：
CIRCUL3_3.1_hero_16x9_01.jpg （红酒晚餐场景Hero主视觉）

CIRCUL3_product_3x4_01.jpg （产品精修图）
```

### 7.3 文件格式

- **主图/精修**：PNG（透明背景）或 JPG（质量95%）
- **场景图**：JPG（质量90%，保留film grain）
- **Web使用**：WebP（压缩后），保留原图备份
- **色彩空间**：sRGB（Web使用），Adobe RGB（印刷使用）

## 八、质量验收清单

每张AIGC素材生成后，必须按以下清单验收：

### 人物验收
- [ ] 年龄符合28-45岁目标人群
- [ ] 皮肤有真实纹理（毛孔/雀斑/细纹），非塑料感
- [ ] 面部为高级脸，非AI网红脸/完美对称
- [ ] 表情自然，符合场景情绪，非标准假笑
- [ ] 80%场景人物不看镜头，专注于动作

### 光线验收
- [ ] 自然光为主，有明确光源方向
- [ ] 非棚拍感/正面平光/闪光灯
- [ ] 阴影柔和，明暗过渡自然
- [ ] 光线类型符合场景（Golden Hour/烛光/窗边光等）

### 质感验收
- [ ] 皮肤有自然光泽/油光，非哑光
- [ ] 戒指为钛金属真实质感，高光自然
- [ ] 戒指尺寸准确（2.23mm超薄），非夸张厚戒
- [ ] 环境材质真实（木/陶瓷/亚麻/玻璃），非人造感

### 色彩验收
- [ ] 低饱和大地色系为主，非高饱和鲜艳色
- [ ] 无科技蓝/赛博朋克紫/医疗白
- [ ] 品牌紫色仅小面积点缀（<5%）
- [ ] 整体色调统一，符合场景调性

### 构图验收
- [ ] 大量留白，人物/产品占30-40%
- [ ] 浅景深，背景虚化（bokeh）
- [ ] 动态瞬间，非静态摆拍
- [ ] 产品（戒指）清晰可见，与场景自然融合

### 功能边界验收
- [ ] 画面无医疗设备/白大褂/实验室场景
- [ ] 无血压计/血氧仪/医疗监测设备
- [ ] 数据可视化（如有）使用合规表述（观察/趋势/参考）
- [ ] 无超出真实功能边界的暗示

**验收通过标准**：以上所有项均通过，方可交付使用。任何一项不通过，必须重新生成或修正。
